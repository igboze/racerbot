# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

NEAR on-chain traders, alpha callers, liquidity providers, multi-wallet runners, and ecosystem token researchers who need high-speed execution, deep wallet distribution analytics, and confidential copy trading.

## Product Purpose

Racer unites decentralized trading, token analytics, copy trading, and multi-wallet management into a single, cohesive interface on NEAR Protocol.

## Positioning

"One account to trade, analyze, copy and manage wallets on NEAR." Enables private intent routing, multi-wallet parallel execution, and on-chain bubble cluster analysis without centralized custodial lock-in or noisy hype.

## Operating Context

Active trading during launchpad bonding curves (JustHoot, NearlyTrade, Meme.Cooking, NearPad, Shore, Ref DEX, InTear) and secondary markets, requiring split-second decisions, clear fee breakdowns, and resilient mobile/desktop interaction.

## Capabilities and Constraints

- **5 Core Product Routes**: Racer Home (`/`), Racer Alpha (`/alpha`), RacerFleet (`/fleet`), RacerBubble (`/bubblemap`), Racer Arena (`/competition`).
- **External Integration**: RacerBot on Telegram (`https://t.me/racertradingbot`).
- **Strict Visual Language**: Dark theme only (`#0F1320` ground), brand cyan (`#6ACCDC`) as the only action color, purple accent (`#7860A9`), DM Sans + JetBrains Mono typography.
- **Transaction Safety**: Every on-chain operation requires a review step before broadcast; 44px minimum touch target across all interactive controls.
- **Copy & Formatting Rules**: No em/en dashes, no emojis in UI icons, tabular figures for all financial values, WCAG 2.1 AA contrast compliance.

## Brand Commitments

- **Master Brand**: Racer.
- **Sub-brands**: RacerBot, Racer Alpha, RacerFleet, RacerBubble, Racer Arena.
- **Voice**: Direct, objective, concise, active voice. No hype, no casino aesthetic, no ungrounded claims.

## Evidence on Hand

- Real-time NEAR RPC / Intent router API (`packages/api`).
- D3-based force-directed bubble map simulation engine (`bubblemap.html`).
- Official logo asset (`assets/racer-logo.png` / `racer_00.png`).
- Centralized configuration module (`assets/racer-config.js`).

## Product Principles

1. **Precision Over Hype**: Fast, calm, high-contrast data presentation without sensory overload or generic SaaS templates.
2. **Predictable Execution**: Clear review steps showing exact fees, slippage, and recipient wallets before any signature.
3. **Real Data Integrity**: Never display synthetic filler numbers, placeholder trader rosters, or fake statistics.
4. **Mobile Ergonomics**: MiniDash 2-column density, non-overflowing data cards, and native-feeling bottom sheets.

## Accessibility & Inclusion

WCAG 2.1 AA compliance across all viewports. Semantic HTML structure, fully accessible keyboard navigation, visible focus rings, non-reliance on color alone (arrows and signs paired with red/green), and explicit ARIA labels.
